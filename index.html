E-voting system

still brewing

Rust · Solidity · Semaphore · Spring Boot · React

A verifiable election platform whose bulletin board is a blockchain no one administers. Ballots are encrypted with exponential ElGamal and carry zero-knowledge proofs checked on-chain; only the final tally is ever decrypted.

PII pseudonymization

Java · FF1 · Spring Batch · PostgreSQL

Format-preserving pseudonymization of personal data for test databases, using FF1 encryption (NIST SP 800-38G) and keyed dictionary substitution in a Spring Batch pipeline. The same phone number gets the same pseudonym in every table, so joins between tables keep working.
